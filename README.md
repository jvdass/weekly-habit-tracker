# 📅 Weekly Habit Tracker

A minimalist weekly habit tracker inspired by Notion's aesthetic. Built with Vanilla JavaScript, it features automatic date calculation, real-time success statistics, and local data persistence via LocalStorage. A simple and effective tool to track your progress.

# 🚀 Features
- **Dynamic Management**: Add or remove habits specifically for each week.
- **Automatic Calculation**: Dynamically determines the Monday of the current week.
- **Statistics**: Success rate calculated in real-time.
- **Persistence**: Local save using `localStorage`.

# 🛠️ Technical Stack
- HTML5 / CSS3 (Grid & Flexbox)
- Vanilla JavaScript (DOM Manipulation, Date API)
